# Retro Cloud

Веб-приложение для облачной эмуляции ретро-игр (курсовой проект).

**Текущий этап:** регистрация и вход пользователей, подключённые к облачной базе данных Supabase (PostgreSQL).
После входа открывается личный кабинет с данными профиля из таблицы `profiles`.

**Технологии:** HTML, CSS, JavaScript, Vite, Supabase (PostgreSQL + Auth).

## Запуск

1. Установите Node.js (версия 18 или новее) с nodejs.org.
2. В папке проекта выполните `npm install`.
3. Скопируйте файл `.env.example` в `.env` и впишите значения из Supabase:
   - `VITE_SUPABASE_URL` — адрес проекта (API URL), без `/` и других приписок в конце;
   - `VITE_SUPABASE_KEY` — публичный ключ (Publishable key).
4. Запустите сайт: `npm run dev` и откройте адрес из терминала (обычно http://localhost:5173).

Если запускаете в PowerShell и видите ошибку про отключённые скрипты, используйте `npm.cmd` вместо `npm`.

## База данных

Схема лежит в `database/schema.sql` (Supabase → SQL Editor → вставить → Run).
Пользователи хранятся во встроенной таблице `auth.users`, а при регистрации триггер автоматически
создаёт строку в таблице `profiles` (имя пользователя и дата регистрации).

## Структура

```
index.html        страница
src/main.js       запуск и переключение экранов (вход / личный кабинет)
src/auth.js       форма входа и регистрации, обращение к Supabase Auth
src/account.js    личный кабинет
src/supabase.js   подключение к Supabase
src/utils.js      вспомогательные функции
src/style.css     оформление (тёмная тема)
database/         схема базы данных
```
